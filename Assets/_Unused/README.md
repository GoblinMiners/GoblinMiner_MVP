# _Unused

Nothing in this folder is referenced by the Menu or DemoLvl scenes, the player/world prefabs,
anything loaded from a Resources folder, or the project settings (checked Nov 2026).

Files keep their original path under this folder (e.g. `Assets/Scenes/Sandbox.unity` is now
`Assets/_Unused/Scenes/Sandbox.unity`) so you can tell where they came from.
Their .meta files moved with them, so dragging something back keeps every reference working.

Safe to delete once you are sure you don't need it.
